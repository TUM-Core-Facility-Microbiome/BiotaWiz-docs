Welcome to the Quick Start guide! Here you'll find everything you need to get up and running with BiotaWiz in just a few minutes.

There are two main ways to use the tool:

- **Graphical User Interface (GUI):**  
  If you prefer a visual, user-friendly experience, check out the [GUI Quick Start Guide](../category/graphical-user-interface).

- **Command Line (using Docker):**  
  For those who like working in the terminal or need automation, see the [Command Line Quick Start Guide](../category/command-line).

Once you're comfortable with the basics, we recommend exploring our [in-depth tutorial](../category/tutorial) for a deeper understanding and advanced usage tips.
